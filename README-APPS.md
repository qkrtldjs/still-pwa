# still — web + SwiftUI prototypes

Two independent monochrome prototypes with a gently moving mind map.

## Web
Open `web/index.html` in a browser. Data is saved in that browser's localStorage. This is not deployed or cloud-synced.

## SwiftUI
On iPad, use Swift Playgrounds to open `swift/Still.swiftpm`. This prototype uses local UserDefaults storage. Build and device installation have not been verified.

## Limitations
The web and SwiftUI versions do not share data. AI connections are based on overlapping words, not a hosted language model. No OpenAI API key is needed. The older `mindspace-pwa` source archive has not been uploaded here.
